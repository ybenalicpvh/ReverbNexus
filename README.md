# ReverbNexus

ReverbNexus is a networked audio-processing framework enabling real-time effects processing across modular server components.

ReverbNexus is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ReverbNexus.git`
2. `cd ReverbNexus`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
